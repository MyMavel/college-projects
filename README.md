# 📋 ระบบบริหารจัดการโครงการ

ระบบเสนอโครงการ อนุมัติ ติดตามงบประมาณ และรายงานผล สำหรับวิทยาลัย
(สร้างจาก webapp-template: Next.js + PostgreSQL + Docker)

## ✨ ความสามารถ

| เมนู | ทำอะไรได้ |
|---|---|
| 📊 ภาพรวม | สรุปตามปีงบประมาณ: จำนวนโครงการแยกสถานะ งบที่อนุมัติ เบิกจ่าย คงเหลือ แยกตามแผนก/งาน และแหล่งงบ พร้อมแจ้งเตือนโครงการที่รอเราอนุมัติ |
| 📋 โครงการ | เสนอ แก้ไข ค้นหา และกรอง (ปีงบ / แผนก / สถานะ) แท็บ "ของฉัน" และ "รอฉันอนุมัติ" พร้อมส่งออกเป็น Excel |
| หน้าโครงการ | แสดงขั้นตอนอนุมัติ ปุ่มอนุมัติ / ส่งกลับแก้ไข / ไม่อนุมัติ บันทึกการเบิกจ่าย รายงานผล ประวัติทั้งหมด และพิมพ์แบบเสนอโครงการ (PDF) |
| 🏢 แผนก/งาน | (admin) เพิ่ม แก้ไข และปิดใช้งาน แผนกวิชา งาน หรือฝ่าย |
| 👥 ผู้ใช้ | (admin) เพิ่มผู้ใช้ กำหนดบทบาทและแผนก และรีเซ็ตรหัสผ่าน |

## 🔄 ขั้นตอนอนุมัติ

```
ครูเสนอ (ร่าง) ─► หัวหน้าแผนก/งาน ─► งานวางแผนฯ ─► ผู้บริหาร ─► ✅ อนุมัติ (ออกเลข 2570-001)
                       │                 │              │              │
                       └── ส่งกลับแก้ไข / ไม่อนุมัติ (ต้องระบุเหตุผล) ──┘     ▼
                                                              บันทึกเบิกจ่าย → รายงานผล → เสร็จสิ้น
```

- ถ้า**หัวหน้าแผนก**เป็นผู้เสนอโครงการของแผนกตัวเอง ระบบจะข้ามขั้นหัวหน้าไปให้อัตโนมัติ
- **admin** (งานวางแผนฯ) อนุมัติแทนได้ทุกขั้น เผื่อกรณีผู้อนุมัติไม่อยู่
- โครงการที่**ส่งแล้ว**ทุกคนในระบบดูได้ ส่วน**ร่าง**เห็นเฉพาะเจ้าของและ admin
- แก้ไขโครงการได้เฉพาะตอนเป็น "ร่าง" หรือ "ส่งกลับแก้ไข"

## 👥 บทบาท

| บทบาท | สิทธิ์ |
|---|---|
| ครู / ผู้รับผิดชอบโครงการ | เสนอโครงการ บันทึกเบิกจ่าย และรายงานผลโครงการของตัวเอง |
| หัวหน้าแผนก/งาน | ทุกอย่างของครู + อนุมัติขั้นแรกให้โครงการในแผนกตัวเอง |
| งานวางแผนฯ / ผู้ดูแลระบบ (admin) | อนุมัติขั้นงานวางแผนฯ (และแทนได้ทุกขั้น) จัดการผู้ใช้ แผนก และทุกโครงการ |
| ผู้บริหาร | อนุมัติขั้นสุดท้าย |

แก้ชื่อบทบาท ชื่อวิทยาลัย และชื่อระบบได้ที่ `lib/site.ts`

## 🚀 ติดตั้งครั้งแรก

### 1. อัปโหลดขึ้น GitHub (repo `college-projects` ที่สร้างจาก template ไว้แล้ว)
แตกไฟล์ zip แล้วเปิด Terminal ในโฟลเดอร์ `college-projects`:
```powershell
git init
git add .
git commit -m "ระบบบริหารจัดการโครงการ"
git branch -M main
git remote add origin https://github.com/MyMavel/college-projects.git
git push -f origin main
```
ใช้ `-f` เพื่อเขียนทับโค้ดตัวอย่างจาก template ที่อยู่ใน repo (ทำครั้งนี้ครั้งเดียว ครั้งต่อไปใช้ `git push` ปกติ)

### 2. ติดตั้งบนเซิร์ฟเวอร์
```bash
cd ~
git clone https://github.com/MyMavel/college-projects.git
cd college-projects
bash deploy/setup-server.sh
```
สคริปต์จะถามชื่อผู้ใช้และรหัสผ่าน admin แล้วทำส่วนที่เหลือให้ทั้งหมด เสร็จแล้วจะแสดงที่อยู่เว็บ เช่น `http://45.136.253.203:8081`

⚠️ ต้องเปิดพอร์ตนั้น (เช่น 8081) ใน **Firewall Rule ของ ReadyIDC** ด้วย

### 3. เปิด Auto Deploy
ที่ repo → Settings → Secrets and variables → Actions
- **Secrets:** `SERVER_HOST`, `SERVER_USER`, `SSH_PRIVATE_KEY` (ค่าเดียวกับ expense-tracker)
- **Variables:** `DEPLOY_ENABLED` = `true`

### 4. ตั้งค่าเริ่มต้นในระบบ (ล็อกอินด้วย admin)
1. เมนู **แผนก/งาน** → เพิ่มแผนกวิชาและงานทั้งหมด
2. เมนู **ผู้ใช้** → เพิ่มผู้ใช้ เลือกบทบาทและแผนก
   - ครูทุกคนต้องมีแผนก (ระบบใช้กำหนดว่าใครเป็นหัวหน้าที่อนุมัติ)
   - ทุกแผนกที่มีครูเสนอโครงการ ต้องมีผู้ใช้บทบาท "หัวหน้าแผนก/งาน" อย่างน้อย 1 คน
3. เมนู **บัญชี** → เปลี่ยนรหัสผ่าน admin

## 🔧 การดูแลระบบ

```bash
cd ~/college-projects
docker compose logs app --tail 50 -f      # ดู log
bash deploy/backup.sh                     # สำรองฐานข้อมูล
bash deploy/reset-password.sh admin       # ลืมรหัส admin
grep PORT .env                            # ดูพอร์ตของแอปนี้ (DB_PORT ใช้กับ DBeaver)
```

**สำรองข้อมูลทุกคืนตอนตี 3:**
```bash
(crontab -l 2>/dev/null; echo "0 3 * * * bash /home/kittithat/college-projects/deploy/backup.sh >> /home/kittithat/backup.log 2>&1") | crontab -
```

**DBeaver:** Host `localhost`, Port ตามค่า `DB_PORT` ใน `.env`, Database `app`, User `app`, Password ตามค่า `POSTGRES_PASSWORD` ใน `.env` ส่วนแท็บ SSH ตั้งค่าเหมือนตอนต่อ expense-tracker
